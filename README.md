# NODEX  
> https://nodex-1314.vercel.app/

Nodex is a modern, real-time collaborative platform that allows users to connect, share, and interact seamlessly. Designed for professional building, Nodex makes collaboration effortless and efficient, user can create post, follow-unfollow others users, can see the personalized feed, and many more features.

## Features
- Seamless user interface for collaboration
- social graph–aware search
- Secure and scalable architecture
- scalable images upload and rendering
- personalized feed based on user prefrences

## Tech Stack
- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Additional Services:** MeiliSearch, Cloudinary
- **Authentication:** Firebase Auth
